# SvelteKit starter

A minimal [SvelteKit](https://svelte.dev/docs/kit) app built with `@sveltejs/adapter-node`, with
Postgres through [Drizzle](https://orm.drizzle.team/), ready to deploy on
[Containify](https://containify.cloud).

- `src/routes/+page.svelte` and `+page.server.ts`: a home page that counts its visits in Postgres
- `src/routes/health/+server.ts`: `GET /health`, the health check
- `src/lib/server/db/`: the Drizzle schema and client, reading `DATABASE_URL`
- `drizzle/`: SQL migrations generated by `drizzle-kit`, applied by `scripts/migrate.js`
- `Dockerfile`: a multi-stage build of the Node server, running as a non-root user

## Run locally

You need Node.js 24 and a Postgres database.

```bash
npm install
cp .env.example .env   # then point DATABASE_URL at your database
npm run db:migrate
npm run dev
```

Open http://localhost:5173.

## Change the schema

Edit `src/lib/server/db/schema.ts`, then generate a migration and commit it:

```bash
npm run db:generate
```

## Deploy on Containify

Deploy the **SvelteKit starter** template from the Containify catalogue. It adds this app, built
from its Dockerfile, and a private Postgres database, with `DATABASE_URL` already set and
`node scripts/migrate.js` as the pre-deploy command, so migrations run before each release
takes traffic.

To deploy your own copy, fork or copy this repository, then add it to a project as a
**Git Repository** app with an HTTP endpoint on port `3000`, a health check on `/health`, and
`DATABASE_URL` set to `{{ "Postgres".DATABASE_URL }}`. See the
[SvelteKit guide](https://containify.cloud/docs/guides/sveltekit).

The Dockerfile sets `PORT=3000` and has the server read `X-Forwarded-Proto` and
`X-Forwarded-Host`, so form actions pass SvelteKit's CSRF check on the `containify.app` address
and on custom domains alike.
